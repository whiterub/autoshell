# MBTI 16가지 성격 유형 웹앱

MBTI 16가지 성격 유형의 특징과 정보를 한눈에 볼 수 있는 인터랙티브 웹 애플리케이션입니다.

## 기능

- **16가지 MBTI 유형 소개**: 모든 MBTI 성격 유형의 상세 정보 제공
- **카테고리별 필터링**: 분석가형(NT), 외교관형(NF), 관리자형(SJ), 탐험가형(SP)으로 분류
- **상세 정보 모달**: 각 유형을 클릭하면 상세 정보를 볼 수 있는 팝업
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 모든 기기에서 최적화된 화면
- **한국어 지원**: 모든 내용이 한국어로 제공

## 포함된 정보

각 MBTI 유형별로 다음 정보를 제공합니다:

- 성격 유형 (예: INTJ, ENFP 등)
- 별칭 (예: 전략가, 활동가 등)
- 카테고리 분류
- 성격 설명
- 주요 특징 (5가지)
- 강점
- 약점
- 추천 직업

## 사용 방법

1. 웹 브라우저에서 `index.html` 파일을 엽니다
2. 메인 화면에서 16개의 MBTI 카드를 확인합니다
3. 상단의 필터 버튼을 클릭하여 원하는 카테고리만 볼 수 있습니다:
   - **전체보기**: 모든 유형 표시
   - **분석가형 (NT)**: INTJ, INTP, ENTJ, ENTP
   - **외교관형 (NF)**: INFJ, INFP, ENFJ, ENFP
   - **관리자형 (SJ)**: ISTJ, ISFJ, ESTJ, ESFJ
   - **탐험가형 (SP)**: ISTP, ISFP, ESTP, ESFP
4. 관심 있는 MBTI 카드를 클릭하면 상세 정보를 볼 수 있습니다

## 기술 스택

- HTML5
- CSS3 (그라데이션, 애니메이션, 반응형 디자인)
- JavaScript (ES6+)
- 순수 바닐라 JS (프레임워크 없음)

## 특징

- 외부 라이브러리 없이 순수 HTML/CSS/JavaScript로 구현
- 빠른 로딩 속도
- 설치 불필요
- 오프라인에서도 사용 가능
